Rychlý start

  1. Založ si zdarma Firebase Realtime Database (test mode).
  2. Otevři Administraci, vlož adresu databáze, ulož.
  3. Naskenuj vygenerovaný QR kód na starém telefonu → objeví se jako nový displej.
  4. Přiřaď mu widget a sleduj, jak ožije.
